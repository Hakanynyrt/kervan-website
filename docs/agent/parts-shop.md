- **Static, no router, no server code.** Every page is prerendered with its props embedded as JSON (`<script id="kv-page">`) and hydrated by `main.tsx`; links are plain `<a>`. Meta robots `noindex, follow` only on the cart (`/palet`) and the 404 pages (`NOINDEX_KINDS` in `src/lib/page-head.ts`); they stay crawlable so the tag is seen. `src/lib/page-head.ts` writes every page's head: titles put make + model + part first and end in `| Kervan Makina` (`meta` in the dict; `og:site_name` stays Kervan Mağaza / Kervan Shop), a self canonical on `SITE`, hreflang tr / en / x-default (= tr), and JSON-LD from `@kervan/seo`: Organization (`@id` `/#organization`, name `ORG_TRADING_NAME`) + WebSite on home, BreadcrumbList mirroring the visible breadcrumb, on breaker, family and part item pages a Product (`shopProduct`, brand Kervan Makina) with an Offer only when the prerendered page shows a price (the net USD price, `valueAddedTaxIncluded: false`, InStock; front heads use the Burçlu price they open on), and a WebPage (`productWebPage`) on quote-only ones, since a Product without offers is an invalid item in Search Console (`sku` only on `/urun/<code>` pages, whose code is public; never ratings or reviews). `prerender.mjs` writes `sitemap.xml` (every indexable page in both languages with `xhtml:link` alternates, `lastmod` = last commit date, build date without git; past 45,000 URLs it becomes an index of `sitemap-N.xml`; one file today, for the 20,000-file limit). `smoke.sh` checks kiriciparca.com has no `noindex` header, `robots.txt` has the Sitemap line and `sitemap.xml` answers 200.
