## Design system

`packages/ui/src/tokens.css` is the single source of truth. Use Tailwind token utilities / CSS variables; never hardcode hex values in components.

- **Contrast:** every text token must stay >= 4.5:1 on `bg`, `bg-soft` and `bg-warm` (`ink-soft` is `#918879` for that reason; check with the WCAG formula before changing it). Form fields use `border-ink-soft` (UI boundaries need 3:1). The WhatsApp button uses `bg-whatsapp` (`#128c7e`, white glyph 4.1:1), not the bright brand green; the shop, whose WhatsApp buttons carry 14 px text, overrides it to `#0f7a6e` (white 5.21:1) in its `globals.css`.
- **Palette ("Mood C", dark):** `bg #0A0A0B`, `bg-soft #141416`, `bg-warm #1C1C20`; `ink #E8E2D6`, `ink-mid #B8AFA0`, `ink-soft #7A7066`; brand "Forge Ember" `#E8431B` (`brand-hi #FF5C32`, `brand-lo #C53614`).
- **Day theme (kervanbreaker.com, kervanheat.com):** light by day, Mood C at night, by the visitor's sun (the same edge middleware as the shop, see `platform.md` "Day / night by the sun"). Day tokens are redefined in each app's `globals.css` under `:root[data-theme='light']` and `:root[data-sun='day']:not([data-theme='dark'])`; no mark ⇒ Mood C (dark-first). Breaker "paper": `bg #F6F3EE`, `bg-soft #EEEAE3`, `bg-warm #E6E0D6`, `ink #1A1714`, `ink-mid #4A433A`, `ink-soft #665D52`, `brand #B0350E` (hover `#962D0B`); heat a shade warmer: `bg #F5F0E8`, `bg-soft #EEE7DC`, `bg-warm #E7DFD2`, `ink #1C1712`, `ink-mid #4B4239`, `ink-soft #645A4E`, `brand #AD340E`. Same rules: every text token >= 4.5:1 on all three backgrounds (lowest: breaker ink-soft 4.92, brand 4.76; heat ink-soft 5.10, brand 4.85 on bg-warm), page colour on brand buttons 5.6:1. Heat's night is Mood C with brighter secondary text (`ink-mid #CEC6B8`, `ink-soft #A8A091`, 6.6:1 or more on all three backgrounds; set unlayered on `:root` in its `globals.css`, the day block still wins by day), its `SectionHeading`s carry `kv-heading` (13 px brand eyebrow, aside as 17 px sans text, both themes), small labels are 13 px `ink-mid`, and the contact fields are bordered boxes (`border-ink-soft` on `bg`). Heat no longer has a `.kv-night` band (its 3D opening was replaced by a photo hero; the 3D gear section `GearProcess` is its own themed block that follows the page theme, so the Nav assumes no dark band, and it keeps the "no AI look" rule: warm light only on the gear's surface, no glow or gradient, brand-token button); breaker's home is light all the way by day, its 3D tip relit for a light studio (`breaker-parts.md`). Brand buttons are `<a>`s whose `text-bg` loses to the global `a { color: inherit }`, so each app's `globals.css` sets their colour explicitly (heat: `a.text-bg` = the page colour in both themes; night `#0a0a0b` on `#e8431b` is 4.95:1). Header theme select: `ThemeSelect` in `@kervan/ui` (`kv_theme`, lg+), copy in each dict's `nav.theme`.
- **Type:** display Fraunces (`--font-serif`), body/UI Inter (`--font-sans`). All three sites serve them themselves (2026-10-28, Lighthouse: the third-party font stylesheet held back the first paint on phones): `public/fonts/inter-latin(-ext)-v20.woff2` (variable 400–700) and, on kervanbreaker and kervanheat, `fraunces(-italic)-latin(-ext)-v38.woff2` (variable 300–700 with the opsz axis), latin + latin-ext only, `@font-face` in each app's `globals.css`, the Inter latin file preloaded, `/fonts/*` immutable. A Google Fonts request for Fraunces must include the italic axis (`ital,opsz,wght@0,…;1,…`), otherwise the browser fakes the italics the headings rely on; the unused `SOFT` axis is not requested.
- **Radius:** 6 / 14 (cards) / 20 (large surfaces) / 999px (pills, buttons).

## Motion

- One ease: `--ease-editorial` = `cubic-bezier(0.22, 1, 0.36, 1)` (`editorialEase` in `@kervan/motion`). Prefer the shared variants over ad-hoc ones.
- Durations: micro 150ms, small 250ms, medium 400ms, large 600ms. Nothing longer than 600ms unless it is a deliberate hero moment. Stagger children 60–80ms.
- In-view reveals animate once (`{ once: true, amount: 0.3 }`); no more than 3 simultaneous animations on screen.
- **`useReducedMotion` is mandatory** in every animated component — short-circuit to the static state. Import it only from `@kervan/motion`, never from `framer-motion`. `globals.css` also has a `prefers-reduced-motion` floor.
- Static vs animated mode: the prerendered HTML is the final static state (no intro curtain, no 3D canvas, no inline hiding). An inline `<head>` script adds `js-anim` to `<html>` only for JS-running humans without reduced motion (bots/headless/webdriver excluded). With `js-anim`, `main.tsx` does `createRoot` (today's animated site; `#root[data-prerendered]` is hidden until the first render, at most 4 s; on kervanheat.com only while the intro curtain is still to come in this visit: the head script adds `kv-intro` when `sessionStorage` lacks `INTRO_SESSION_KEY` (`src/lib/intro.ts`), so later pages show the static markup at once instead of a blank screen; 2026-10-28, owner: curtain on the first page only); otherwise it `hydrateRoot`s in static mode (`StaticMotionProvider`, where `useReducedMotion()` is true) and must match the server markup exactly. Heavy effects (the 3D scene) mount client-side only: three.js is reached only through a dynamic `import()` after idle and near the viewport, never in the prerender, and reduced motion, Save-Data or a WebGL failure show the static poster instead (heat's `GearProcess` is the pattern).
- Intro: heat-treatment's `IntroOverlay` shows once per session (breaker-parts has none) (`sessionStorage`). Hero sequences must account for it (delay until it finishes, or skip the delay when the session flag is set).

## Accessibility

- WCAG AA contrast: 4.5:1 body text, 3:1 large text and non-text UI.
- Focus ring: `2px solid` brand with `outline-offset: 2px` (`focus-visible:outline focus-visible:outline-2 focus-visible:outline-brand focus-visible:outline-offset-2`). Restyle focus rings, never remove them.
- Tap targets (kiriciparca.com, 2026-10-27): below `lg`, WhatsApp, phone and order links and the header quote button are at least 44 px high (`min-h-11`), reached with padding, never with a larger font; an inline text link gets vertical padding (`max-lg:py-[14px]`), which enlarges its hit area without moving the line.
- Every interactive element (buttons, links, form fields, carousel/gallery controls, language toggle, menu) must be keyboard-reachable and Enter/Space-activatable.
