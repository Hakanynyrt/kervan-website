## heat-treatment (kervanheat.com)

- Single-page site (served at `/` and `/en/`): `src/App.tsx` composes the sections in `src/components/`. No router. The only 3D is the gear section `GearProcess` (below), lazy-loaded.
- **Look and order (owner-approved redesign "D: Karışım", 2026-10-28):** Inter only (no Fraunces, no serif italics), no eyebrow kickers, 2 px buttons, 4 px frames, ember only on actions and links. Shared class strings in `src/lib/ui.ts` (`WRAP` 1240 px with 32 / 16 px gutters, `H2` 40 / 30 px, `BTN_PRIMARY`, `BTN_LINE`, `SEC_HEAD`); phone breakpoint 720 px (`max-[720px]` / `min-[721px]`). Section order: Nav → Hero (`#top`) → capacity spec table (`TechnicalCapacity`, `#teknik-kapasite`) → furnace film (`HeroFilm`) → gear (`#surec`) → Services (`#hizmetler`, grey band) → TechInfo (owner only) → Tesisimiz (`Craft`, `#tesisimiz`) → About (`#hakkimizda`, grey band) → Contact (`#contact`) → Footer. The header is sticky (`bg-bg`, hairline; 68 / 60 px): logo, five links (from 1100 px, else the "Menü" button), a TR | EN pair (`nav.langShort`, current one `aria-current`), the theme select (lg+), "Teklif Al". No sister-site strip on this site any more (the footer and the second service card link both sister sites).
- **Palette** (tokens in `src/styles/globals.css`, never hex in components): day bg `#FFFFFF`, bands `bg-soft #F5F6F7`, `panel #FFFFFF`, hairlines `hair #E2E5E8` / `hair-strong #C9CED4`, `field-line #868D96`, ink `#15171A`, `ink-mid` = `ink-soft #646B74`, ember `brand #C23A16` (hover `#A8320F`) with white labels (`on-brand`); night (the default without a mark) graphite `bg #1A1D20`, `bg-soft #202427`, `panel #24282C`, `hair #383D42` / `#4A5056`, `field-line #727A83`, ink `#ECEAE6`, `ink-mid #A5A9AD`, a lighter ember `brand #F26A45` (hover `#FF8259`) with a dark label `on-brand #16110E`. Spec table head bar `spec-head` (`#15171A` / `#2E3338`) and frame `spec-rule` (`#15171A` / `#6B7279`). Contrast (WCAG): text ≥ 4.5:1 everywhere (lowest: day ink-mid 4.98 and brand 4.96 on bg-soft, night brand 4.89 on panel), UI ≥ 3:1 (field borders 3.35 / 3.41, night spec frame 3.47); ratios listed in the globals.css comment. `theme-color` `#FFFFFF` / `#1A1D20` (index.html script, `Nav` `THEME_COLOR`).

Photo: `public/photos/isil-islem/hero-pota-01-1280.webp` (1280×720) in a box capped at 1280 px and centred, so it is never upscaled (80 px page-coloured gutters at 1440 px), `object-position 50% 72%`, caption chip `hero.photo.caption` "Fırın ağzı" bottom right; phones (`<source media="(max-width: 720px)">`) `hero-pota-telefon-01-1080.webp` (1080×1920) as a 132 px band at `50% 63%` so the open pot fills it. - `src/components/TechnicalCapacity.tsx` (`#teknik-kapasite`, right under the hero): a framed **spec table** (`<table>`, sr-only caption `capacity.aside`) with a head bar (h2 `capacity.eyebrow` "Teknik Kapasite" + `capacity.title`) and five cells from `capacity.items` (`label`, `value`, `unit`, `note`), in this order: Max parça çapı Ø1200 mm · **Max parça boyu 2,6 m, note "Pota iç derinliği"** (owner, 2026-10-28: the pot's inner depth is 2,6 m) · Tek sefer max yük 2,5 ton · Temper potası 2 · Standart alaşımlar 42CrMo · 42CrMoA; then a footer row `services.quality` ("Her partide sertlik ölçüm raporu"; its body hidden on phones). Desktop 5 in a row (the alloy column 1.45× wider), 721–1080 px 3 + 2, phones 2 × 2 plus the alloy cell at full width. On a 390×844 phone the first screen holds the H1, Teklif Al + Telefon, the whole table and the report row (bottoms at 268 / 404 / 713 / 756 px). These figures are shown only here (the hero has no stats any more). The figures are the owner's: never change or add one without him.
- `src/components/HeroFilm.tsx` — the furnace loop (`/videos/isil-islem/firin-hatti-loop-01*`; copy in the dict's `hero.film`). **Place:** its own full-bleed band after the capacity table (`App.tsx`), `min(56vw, 600px)` tall (240 px on phones), so it is never in the first 390×844 screen. On its bottom edge: the play / pause button (an ember square with the icon + the visible label `play` / `pause`) and the caption chip. It always uses the `-wide` poster/mp4 (the portrait files are unused now). Static mode renders only the poster `<picture>`; the `<video>` mounts client-side `startAt` seconds (default 1) after hydration, then on idle, on 4g without Save-Data, when the band is ≥ 25 % on screen, and starts at `START_AT` = the poster frame (re-extract both posters if that changes). Reduced motion = poster only, no button. A load/decode error (404, no H.264) falls back to the plain poster without the button. The pause button is required (WCAG 2.2.2). Any re-encode gets a new filename.
- `src/components/GearProcess.tsx` (`#surec`, copy in the dict's `gear`) — "Parçanın ısıl işlem yolu": a 3D spur gear (owner-approved concept "Sakin soğuma") placed right **after the hero, the capacity table and the film**, so the first screen stays the photo hero. Animated visitors get a pinned stage (`h-[200svh]` section below `lg`, `lg:h-[300svh]` from `lg`: owner, 2026-10-28, the phone version was too long;, `sticky top-0 h-svh` stage; `svh`, never `dvh`); scroll progress P (0.36 = the hot frame, the scene warms up to it by itself, then scrolling drives it) walks four stages: Isıtma → Su verme → Temperleme → Rapor. The stage tabs are real buttons that scroll to their stage (`TAB_P`), each stage has a one-line description (`gear.stages`, only existing claims: pit-tip heating to hardening temperature, "Kontrollü soğutulur." (no oil/air/water named: steam is shown, the services text names oil or air), temperleme, hardness report per batch), the bar is the steel's colour scale (`SCALE`) with a tick at the real progress, and the report card ("Sertlik ölçüm raporu / Her partide") shows in the Rapor stage. No numbers, temperatures or hardness values anywhere in the copy (the shader's temperature field is illustration only). Gear slowly turns (5°/s); steam only in the quench stage.
  - 3D code: `src/lib/gear-scene.ts` (three, plain WebGL, one shader material). **three loads only through `import('../lib/gear-scene')`** (its own ~565 kB chunk): after `useClientIdle` AND when the section is within a screen of the viewport (IntersectionObserver); never in the prerender. Full-detail geometry and antialiasing on every device (2026-10-28: the low-poly outline looked jagged on phones; the tooth-root fillet is 45 % of the root gap, a fixed 0.058 rad overlapped and left a spike at every root), DPR cap 1.5 on coarse pointers / narrow screens, ~30 fps cap (45 ms frames on touch), rendering pauses off-screen (IntersectionObserver) and on a hidden tab, ResizeObserver layout, `webglcontextlost` shows the poster again and `restored` brings the canvas back. Layout numbers (gear centre/size, report-card place) are computed in `GearProcess` (`layout()`: side by side from 1000 px wide with a wide enough aspect, else stacked: text on top, gear in the gap above the stage bar) and shared by the poster (CSS variables `--gx/--gy/--gd`) and the canvas. Theme: the scene reads the page theme every frame with the same rule as the tokens (`data-theme` wins, else `data-sun='day'` = light, no mark = night); the warm light is only on the gear's surface (the ground plane only holds a soft shadow; no glow, halo or gradient).
  - Poster: `public/photos/isil-islem/gear-poster-day-01.webp` and `gear-poster-night-01.webp` (1000×1000, transparent, the hot frame), both in the DOM, CSS (`.kv-gear-img-*` in `globals.css`) shows the one matching the theme. A changed poster gets a new name (`-02`). **Poster block** (no canvas, no pin: a normal section with the poster in a 4 px frame on the left, then the copy, the four stages as a numbered list (`gear.stages[].no`), the report card and "Teklif Al") is used for the prerender, hydration (`useReducedMotion()` is true in static mode), reduced motion, `Save-Data` and any 3D failure (chunk load error, no WebGL); a failure while the visitor is inside the pinned section swaps to it.
